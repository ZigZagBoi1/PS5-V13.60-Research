# V14.10 project attribution

The V13.60 work in this repository is related to, but distinct from, the [PS5 V14.10 Research](https://github.com/ZigZagBoi1/PS5-14.10-Research) project.

The V14.10 repository contains `docs/ps5_13.60_sysent.json`, a compatibility copy consumed by its existing strategy/probe tooling. The research copy is maintained here at `docs/ps5_13.60_sysent.json`; the V14.10 copy remains in place so its current scripts continue to work.

Firmware-specific results should be attributed to the repository and firmware they actually cover. Shared upstream sources are credited in this repository's submodules and in `site/HV-INTEGRATION.md`.
