MANUAL WEBKIT REGRESSION

TransformStream single-case check

This runs one reduced case from WebKit's published CVE-2026-43705 regression: one TransformStream construction while the frame's array iterator substitutes a plain object.

Browser stability: affected code may terminate the browser process. This runs one constructor call and one iterator override in an isolated frame, with no repeat or user-sized allocation. The page never starts automatically and never retries.

The five-second deadline is soft; JavaScript cannot stop a hung renderer. A timeout means no frame result arrived, and does not prove the case executed or crashed. If the browser or console hangs or restarts, do not run it again. No code execution, arbitrary memory access, or kernel access is attempted.

Expected safe handling in the fixed upstream implementation is a TypeError. That result would not prove which implementation the PS5 firmware contains.
