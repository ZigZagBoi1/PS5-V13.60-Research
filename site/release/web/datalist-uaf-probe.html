ONE MANUAL WEBKIT LIFETIME CHECK

Datalist control check

This checks one source-backed WebCore lifetime path: a page click listener changes an input from text to button while the browser’s own datalist control is dispatching a click. Sony’s published WebKit source has the pre-fix raw-owner pattern; its correspondence to PS5 14.10 is unverified.

Possible browser impact: the browser may close or freeze if the suspected lifetime defect is present. The page makes no synthetic click, forced collection, heap churn, or repeated attempt. If the browser closes, freezes, or the console restarts, do not run it again.

A normal return, an exception, an absent control, or missing telemetry does not confirm or refute a use-after-free. This test does not seek code execution, arbitrary memory access, kernel access, or a jailbreak.

Run provenance

Browser and source hashes are attached automatically. Device and firmware labels are self-reported.

Manual control

First check whether the browser visibly shows its own datalist arrow/control for this input. Do not select an option. The page cannot inspect a closed browser shadow tree, so visibility is your observation.

If the browser’s own dropdown control is visible, start the run and confirm that you can see it. The armed test accepts one trusted mouse click in the rightmost 44 CSS pixels of this input. A click elsewhere is recorded without changing the input.
